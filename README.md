# NUFA Gaming Turf ⚽🏏🏐

A modern, responsive landing page for **NUFA Gaming Turf** (Siruseri, Chennai) built with React.js and Tailwind CSS.

![NUFA Gaming Turf](https://images.unsplash.com/photo-1575361204480-aadea25e6e68?auto=format&fit=crop&w=1200&q=80)

## Features
- **Hero Section**: Stadium floodlights effect, bold athletic typography, sports selector (Football, Cricket, Volleyball), and the signature "GAME ON ALWAYS" brush sticker badge.
- **Features Strip**: Premium Turf, Bright Lighting, Safe & Secure, Clean Facilities, Parking Available.
- **Our Facilities**: Cards for Football Turf, Cricket Turf, Volleyball Court, and Virtual Tour with 360-degree interactive preview.
- **Gallery**: Smooth carousel slider with real turf action photos and lightbox viewer.
- **Book Your Slot**: Interactive slot booking form with WhatsApp redirection, operating hours (6:00 AM – 11:00 PM), and custom styled location map with Siruseri pin marker.
- **Mobile Optimized**: Custom fixed bottom navigation bar for mobile devices matching modern sports turf apps.

## Quick Start
Open `index.html` in your browser or run:
```bash
node server.js
```
Then visit `http://localhost:3000`.
